# المنصة الألمانية الشاملة (Deutsch All-in-One Platform)

منصة تعليمية متكاملة تجمع بين مشروعين رائدين في تعلم اللغة الألمانية في موقع واحد متناغم دون أدنى تعديل على وظائف أي منهما، مع إمكانية التبديل الفوري بنقرة واحدة:

1. **📚 بنك المفردات التفاعلي ومُعلّم النطق (Vocab Tutor - sprechen1 v16):**
   - استخراج ذكي للجداول من ملفات PDF و Word.
   - تصنيف نحوي لحالات النصب والجر (Akkusativ & Dativ).
   - تشغيل النطق الصوتي وتصريف الماضي التام (Perfekt).
   - تصدير قوائم المفردات التفاعلية بصيغة Word و HTML.

2. **🎙️ مدرب المحادثة والنطق الصوتي بالذكاء الاصطناعي (German Coach v18):**
   - إدخال صوتي مستمر ومباشر (Web Speech Recognition).
   - تصحيح سياقي فوري للأخطاء عبر نماذج Google Gemini.
   - إبراز بصري دقيق للفروقات بين النص المنطوق والمُصحح (Visual Diff).
   - رادار القواعد اللغوية (Grammar Error Radar).
   - الحافظة الذكية للعبارات والكلمات (Smart Clips).

---

## 🚀 كيفية الوصول والتشغيل
يعمل الموقع موحداً على السيرفر عبر المنفذ **`8095`**:
* **المنصة الموحدة مع زر التبديل المباشر:** `http://SERVER_IP:8095/`
* **عرض بنك المفردات مباشرة:** `http://SERVER_IP:8095/vocab/`
* **عرض مدرب المحادثة مباشرة:** `http://SERVER_IP:8095/coach/`

### اختصارات لوحة المفاتيح السريعة:
* `Alt + 1` أو `Ctrl + 1`: الانتقال إلى بنك المفردات التفاعلي.
* `Alt + 2` أو `Ctrl + 2`: الانتقال إلى مدرب المحادثة والنطق.
* `F11` أو `Esc`: التبديل إلى وضع ملء الشاشة لإخفاء الشريط العلوي والتركيز.

## 🔒 الأمان وإدارة الإصدارات
* مفاتيح الـ API مخزنة محلياً فقط في `.env` ومحمية بواسطة `.gitignore`.
* حفظ الإصدارات تلقائياً عبر الأمر:
  ```bash
  save-version "وصف التحديث"
  ```
* إمكانية الرجوع لأي إصدار بنسبة 100% وبكل بايت:
  ```bash
  rollback-version v1
  ```

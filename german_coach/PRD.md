# وثيقة متطلبات المنتج (PRD) - German Coach

## 1. نظرة عامة على المشروع (Project Overview)
**الاسم:** German Coach (مصحح الألمانية السياقي الطلقة + رادار الأخطاء B1–C2)  
**طبيعة الاستخدام:** استخدام شخصي وتطوير ذاتي مكثف لإتقان اللغة الألمانية للمستويات المتقدمة (B1 – C2).  
**الهدف الأساسي:** تمكين المستخدم من التحدث والكتابة بالألمانية بطلاقة وثقة، مع معالجة التردد والكلمات المفقودة عبر الترجمة السياقية الفورية للكلمات العربية المدمجة بالجمل، وتصحيح الأخطاء النحوية بدقة فائقة، وتتبع نقاط الضعف المتكررة عبر رادار أخطاء ذكي.

---

## 2. التقنيات الثابتة المعتمدة (Technology Stack)
1. **واجهة برمجة التطبيقات الخلفية (Backend API):**
   - **FastAPI (Python 3.12+):** معمارية غير متزامنة خفيفة وسريعة الأداء.
   - **Pydantic v2:** للتحقق من صحة البيانات وبناء النماذج الصارمة للطلبات والاستجابات.
   - **Uvicorn:** خادم ASGI عالي السرعة.
2. **قاعدة البيانات (Database):**
   - **SQLite (`data/german_coach.db`):** قاعدة بيانات مدمجة، سريعة، وبدون حاجة لإدارة خوادم خارجية، مع الاستفادة من SQLite Online Backup API لمنع أي تعطل أثناء النسخ.
3. **محرك الذكاء الاصطناعي (AI Engine):**
   - **Google Gemini API (`google-genai`):** استخدام النموذج فائق السرعة والدقة `gemini-2.5-flash` لإنتاج استجابات بصيغة JSON محكمة تشمل التصحيح، ترجمة الكلمات العربية، تصنيف الأخطاء للرادار، وشرح الفروق السياقية.
4. **المعالجة الصوتية (Speech & Voice):**
   - **صوت المتصفح المجاني (Web Speech API / SpeechSynthesis):** توليد النطق الألماني الطبيعي محلياً وبالمجان عبر محرك المتصفح.
   - **نظام المايك المزدوج (Dual-Mic Approach - الخيار 3):** التقاط صوتي تلقائي سلس بدون تعقيدات، مع توفير أزرار تحكم يدوي كاملة (بدء/إيقاف/إعادة المحاولة).
5. **إدارة النسخ الاحتياطي (Automated Backups):**
   - **Telegram Bot API:** تصدير نسخة احتياطية مضغوطة من قاعدة بيانات SQLite وإرسالها دورياً أو يدوياً إلى محادثة تليجرام خاصة وآمنة.
6. **إدارة النسخ المستمرة (Version Control):**
   - نظام إدارة النسخ الخطي التلقائي عبر أوامر النظام: `save-version` و `rollback-version` مع الرفع المباشر إلى GitHub.

## 3. الوظائف والميزات الأساسية (Core Features)

### 3.1 تصحيح الجمل الألمانية الذكي (B1–C2)
- استيعاب الجمل الألمانية بأسلوب دقيق يراعي المستوى المستهدف (B1, B2, C1, C2).
- التفريق بين الأخطاء القواعدية الحتمية (Grammar Mistakes) والتحسينات الأسلوبية المتقدمة (Stylistic / Idiomatic Enhancements).

### 3.2 الترجمة التلقائية للكلمات العربية داخل السياق (Arabic-in-German Code-Switching)
- إذا واجه المستخدم كلمة أو تعبير ألماني لا يتذكره واستبدله باللغة العربية داخل الجملة (مثال: *"Ich möchte ein Buch über التاريخ kaufen"* أو *"Er hat das بدون قصد gemacht"*):
  - يتعرف النظام تلقائياً على الكلمات العربية وسياقها.
  - يستبدلها بالمصطلح الألماني الطبيعي الأنسب للسياق والمستوى المطلوب.
  - يُبرز الكلمات المترجمة في تقرير منفصل يوضح البدائل الألمانية.

### 3.3 العرض البصري المقارن (Visual Diff)
- توليد مقارنة بصرية واضحة وفورية بين النص الأصلي والنص المصحح:
  - **اللون الأحمر:** الكلمات المحذوفة أو الخاطئة.
  - **اللون الأخضر:** الكلمات المضافة أو المصححة أو المترجمة.

### 3.4 أمثلة سياقية وشرح نحوي موجز (Contextual Examples & Explanations)
- تقديم 2-3 جمل إضافية توضح كيفية استخدام الكلمات أو التراكيب المصححة في مواقف حياتية وعملية حقيقية.
- تقديم شرح لغوي موجز باللغة العربية أو الألمانية يوضح سبب التصحيح (Rule Explanation).

### 3.5 رادار الأخطاء النحوية (Grammar Error Radar)
- تصنيف كل خطأ نحوي إلى فئات معيارية دقيقة، منها:
  - **Kasus (الحالات الإعرابية):** Dativ, Akkusativ, Genitiv.
  - **Wortstellung (ترتيب الكلمات في الجملة):** Hauptsatz, Nebensatz, Inversion.
  - **Adjektivdeklination (تصريف الصفات).**
  - **Verben mit Präpositionen (الأفعال مع حروف الجر).**
  - **Konjunktiv II & Passiv (الصيغ الشرطية والمبني للمجهول).**
  - **Artikel & Genus (أدوات التعريف والتنكير والأجناس).**
  - **Präpositionen (حروف الجر الزمانية والمكانية).**
- حفظ وتجميع التكرارات في قاعدة البيانات لتقديم إحصائيات بيانية ورادار تفاعلي يحدد نقاط الضعف الأكثر تكراراً للمستخدم لمساعدته على التركيز عليها.

## 4. تصميم البيانات والـ Endpoints (Data & API Design)

### 4.1 نموذج قاعدة البيانات (SQLite Schema)
- جدول `corrections`:
  - `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
  - `original_text` (TEXT)
  - `corrected_text` (TEXT)
  - `level` (TEXT: B1, B2, C1, C2)
  - `explanation` (TEXT)
  - `arabic_translations` (JSON/TEXT)
  - `diff_data` (JSON/TEXT)
  - `contextual_examples` (JSON/TEXT)
  - `created_at` (TIMESTAMP DEFAULT CURRENT_TIMESTAMP)
- جدول `error_logs`:
  - `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
  - `correction_id` (INTEGER FOREIGN KEY)
  - `category` (TEXT - تصنيف الخطأ للرادار)
  - `error_text` (TEXT - الجزء الخاطئ)
  - `correction_text` (TEXT - التصحيح)
  - `explanation` (TEXT - سبب الخطأ)
  - `created_at` (TIMESTAMP DEFAULT CURRENT_TIMESTAMP)

### 4.2 مسارات واجهة التطبيقات (API Endpoints)
- `GET /api/health`: فحص صحة الخادم، قاعدة البيانات، والتحقق من حالة ضبط المتغيرات (`GEMINI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) بدون كشف قيمها.
- `POST /api/correct`: إرسال نص ومستوى لتحليله وتصحيحه وحفظه واستخراج تصنيفات الرادار.
- `GET /api/history`: استرجاع أحدث التصحيحات المسجلة في قاعدة البيانات.
- `GET /api/radar`: استرجاع ملخص إحصائيات الأخطاء وتوزيعها حسب التصنيف لتغذية رادار الأخطاء.
- `POST /api/backup/telegram`: أخذ نسخة احتياطية آمنة من قاعدة بيانات SQLite وإرسالها لمحادثة تليجرام.

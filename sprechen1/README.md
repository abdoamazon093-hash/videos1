# قاموس ومُعلّم النطق التفاعلي — Vocab Tutor (German B2 Platform)

منصة تفاعلية متقدمة لدراسة المفردات الألمانية بمستوى B2، مع دعم النطق الصوتي الفوري، أزمنة الماضي البسيط والماضي التام (Präteritum & Perfekt)، مكتبة كتب ومستندات مستقلة، ونظام حفظ ومراجعة دائم.

---

## ✨ المميزات الرئيسية
1. **مكتبة المستندات المستقلة (Isolated Multi-Document Pages):**
   - كل ملف Word أو PDF يتم رفعه ينشئ صفحة دراسة منفصلة بالكامل بدون أي اختلاط بين الكلمات.
2. **استخراج ذكي متقدم للجداول والمستندات (Smart Extractor):**
   - التعرف التلقائي على أعمدة الجداول (`Infinitiv` / `المصدر`, `Präteritum` / `الماضي البسيط`, `Perfekt` / `الماضي التام`, `المعنى بالعربية`, `الأمثلة التطبيقية`).
   - استبعاد أعمدة الترقيم تلقائياً.
3. **نطق صوتي تفاعلي (Interactive Web Speech TTS):**
   - نطق صوتي فوري للكلمة الأصلية، صيغة الماضي، والبيرفكت، مع التحكم في سرعة النطق واختبار الصوت.
4. **نظام الحفظ الدائم (Dual-Layer Persistence):**
   - حفظ تلقائي للكلمات المحفوظة ✅ وقائمة المراجعة ⭐ في ذاكرة المتصفح وقاعدة البيانات الخلفية دون أي فقدان عند إغلاق المتصفح.
5. **تصدير مستقل أوفلاين (Standalone HTML Export):**
   - إمكانية تصدير أي ملف كصفحة HTML تفاعلية كاملة تعمل أوفلاين بنسبة 100% بدون إنترنت أو خادم خارجي.

## 💻 طريقة التشغيل على الكمبيوتر الشخصي (Desktop - Windows / Mac / Linux)

### 1. المتطلبات:
- تثبيت [Python 3.10+](https://www.python.org/downloads/).

### 2. التثبيت والتشغيل:
1. افتح موجه الأوامر (CMD أو PowerShell أو Terminal) داخل مجلد المشروع:
   ```bash
   pip install -r requirements.txt
   ```
2. ضع ملف قاعدة البيانات `sprechen.db` في المجلد الرئيسي بجانب هذا الملف.
3. شغّل الخادم المحلي:
   ```bash
   uvicorn app.main:app --port 8085
   ```
4. افتح المتصفح على الرابط التالي:
   ```text
   http://localhost:8085
   ```

## 🛠️ هيكلية المشروع
- `app/main.py`: نقطة انطلاق تطبيق FastAPI.
- `app/routers/`: مسارات الـ API (المفردات، استخراج الملفات، النسخ الاحتياطي، التصدير).
- `app/services/`: محركات المعالجة الذكية (استخراج الجداول، النطق، التصدير المستقل، فحص الأفعال).
- `app/static/index.html`: الواجهة التفاعلية الكاملة للمنصة.
- `tests/`: حزمة الاختبارات الآلية الشاملة (16 اختباراً).
